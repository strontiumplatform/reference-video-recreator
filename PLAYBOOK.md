# Reference Video Recreator — Playbook v2
Read [SYSTEM_PROMPT.md](SYSTEM_PROMPT.md) in full: it is the complete workflow, including intake, reference analysis, continuity, mandatory settings, shot generation, captions/editing and verified delivery.

User requests override defaults. The current system prompt controls inherited supporting examples. Default Landscape 16:9; verify Creative Mode ON before every Create Image, including anchors and retries. Duration/pacing follow the reference, otherwise 30 seconds. Default neutral British English; never infer accent from silent frames.

## Working artifacts
Keep private media and derived frames in ignored work/ or outputs/.
1. Metadata and timestamped frame manifest/contact sheet.
2. [Reference Blueprint](templates/reference-blueprint.md), with evidence versus inference clearly labeled.
3. Character, wardrobe, voice, prop and world locks.
4. [Shot plan](templates/shot-plan.csv) mapping source beats to new beats.
5. [Production ledger](templates/production-ledger.csv) for accepted jobs, retries and resume state.
6. Actual caption timing and verified offer text.
7. Saved project and completed export link, with limitations.
